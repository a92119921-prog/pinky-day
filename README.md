# Pinky Day 粉日常

Cute Daily Calendar App — 把每一天，過得可愛一點。

## 第一版功能
- 月曆檢視與月份切換
- 選擇日期並新增／刪除行程
- 行程時間與分類顏色
- 待辦事項新增、完成與刪除
- 手機優先的粉色介面
- 使用瀏覽器 localStorage 暫存資料（目前僅保存在這台裝置／瀏覽器）

## 開發
```bash
npm install
npm run dev
```

## 建置
```bash
npm run build
```
